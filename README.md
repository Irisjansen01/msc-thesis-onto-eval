# Automated Ontology Evaluation in an LLM Generation Context

MSc thesis repository — University of Amsterdam.

The thesis investigates how automated ontology evaluation methods can be interpreted when applied to LLM-generated ontologies. The central problem is that automated methods produce numbers, flags, and match scores, but those outputs do not all support the same kind of quality claim. The project separates what a method does, what its output is, what quality concern it speaks to, and what can and cannot be concluded from it.

## Research Design

Two phases:

**Phase 1 — Taxonomy construction via card sort.** Forty method cards were sorted by 13 domain experts into four top-level categories (reference-based, corpus/data-based, task/application-based, criteria-based). The result is a taxonomy of 40 automated ontology evaluation methods with placement stability labels grounded in a Bonferroni-corrected binomial test.

**Phase 2 — Case study comparison.** Six methods selected from Phase 1 were applied to two LLM-generated ontologies (music production and hospital employment domains). Outputs are compared across domains to examine which results are content-sensitive and which mainly reflect method preconditions.

## How to Reproduce

### Phase 1 — Card Sort Analysis

```powershell
python scripts\phase1\phase1_report.py
```

Reads all 13 JSON exports from `results/phase1/card-sort-responses/` and writes all tables, plots, and `phase1_summary.txt` to `results/phase1/`.

Key outputs:

| File | Contents |
|---|---|
| `phase1_summary.txt` | N, α, per-card agreement rates and stability labels, band counts, set-aside stats |
| `card_sort_per_card_agreement.csv` | Majority category, k, agreement rate, stability for all 40 cards |
| `card_sort_boundary_votes.csv` | Vote breakdown for boundary (k∈{7,8}) and unstable (k≤6) cards |
| `cooccurrence_matrix_ordered.png` | 40×40 heatmap of pairwise co-placements, grouped by taxonomy category |
| `participant_card_heatmap.png` | 13×40 grid coloured by category placement per participant |

### Phase 2 — Ontology Evaluation

```powershell
python scripts\phase2\evaluation_phase_II.py
```

Runs five evaluation methods on both generated ontologies and writes results to `results/phase2/`.

| Method | Output folder | What it measures |
|---|---|---|
| Basic statistics | `basic_statistics/` | Entity counts, axiom counts, annotation coverage |
| OQuaRE | `oquare/` | 15 structural metrics scaled 1–5, aggregated into subcharacteristics and characteristics |
| CQ coverage | `cq_coverage/` | SPARQL answerability of 15 competency questions per domain |
| Vocabulary profile similarity | `vocabulary_profile_similarity/` | Token overlap between ontology labels and domain story (precision, recall, F1) |
| Maedche-Staab similarity | `maedche_staab_music/`, `maedche_staab_hospital/` | Lexical, taxonomic, and relation overlap against the reference ontology |

OOPS! and FOOPS! results are not generated by this runner. Their output folders are placeholders for manually exported reports from the respective web tools.

## Interpreting Outputs

Automated outputs need interpretation before they support a quality claim. Specifics:

- A high **OQuaRE** score depends on the implemented metric mapping and published threshold choices.
- A positive **CQ coverage** result means the encoded SPARQL query returned data, not that all competency requirements are satisfied or that answers are semantically correct.
- A high **vocabulary profile** F1 indicates lexical overlap with the source story, not conceptual correctness or relation-level modelling quality.
- A high **Maedche-Staab** similarity indicates closeness to the chosen reference ontology, not absolute quality — the reference may itself be incomplete or reflect different modelling choices.
- **OOPS!** and **FOOPS!** outputs carry their own tool-specific assumptions and coverage limits.

The thesis examines each output through a Toulmin argumentation schema: data → claim via warrant, with explicit rebuttal conditions. The method–output–claim mapping is in Table 5 of the thesis.
