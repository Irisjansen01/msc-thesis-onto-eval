Generation procedure
--------------------
One LLM call per competency question (15 calls per domain).
Each call was stateless — {rdf} slot passed as empty string.
Per-CQ Turtle outputs were merged post-hoc using rdflib Graph addition,
which deduplicates triples that appear in multiple modules.

See scripts/phase2/generate_ontologies.ipynb for the full implementation.
See data/phase2/generation/prompt_template.txt for the exact prompt used.
