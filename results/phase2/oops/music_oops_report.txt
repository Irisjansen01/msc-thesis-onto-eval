Results for P04: Creating unconnected ontology elements. Minor — 1 case
Ontology elements (classes, object properties and datatype properties) are created isolated, with no relation to the rest of the ontology.

• This pitfall appears in the following elements:
  › http://www.example.org/ontology/music#Cl_Entity

Results for P08: Missing annotations. Minor — 73 cases
This pitfall consists in creating an ontology element and failing to provide human readable annotations attached to it. Consequently, ontology elements lack annotation properties that label them (e.g. rdfs:label, lemon:LexicalEntry, skos:prefLabel or skos:altLabel) or that define them (e.g. rdfs:comment or dc:description).

Results for P19: Defining multiple domains or ranges in properties. Critical — 5 cases
The domain or range (or both) of a property is defined by stating more than one rdfs:domain or rdfs:range statement. In OWL, multiple rdfs:domain or rdfs:range axioms are interpreted as conjunction (owl:intersectionOf).

• This pitfall appears in the following elements:
  › http://www.example.org/ontology/music#hasPerformance
  › http://www.example.org/ontology/music#hasTrack
  › http://www.example.org/ontology/music#performedBy
  › http://www.example.org/ontology/music#hasMember
  › http://www.example.org/ontology/music#memberOf

Results for P22: Using different naming conventions in the ontology. Minor — Ontology-level
The ontology elements are not named following the same convention (e.g. CamelCase or use of delimiters such as "-" or "_").

Results for P35: Untyped property. Important — 1 case

• This pitfall appears in the following elements:
  › http://www.example.org/ontology/music#hasPart

Results for P38: No OWL ontology declaration. Important — Ontology-level
The owl:Ontology tag is not declared. This tag provides ontology metadata such as version information, license, provenance, and creation date.

Results for P39: Ambiguous namespace. Critical — Ontology-level
Neither the ontology URI nor the xml:base namespace is declared. The ontology namespace defaults to the file location, which is not stable.

Results for P41: No license declared. Important — Ontology-level
The ontology metadata omits license information.
