# Analysis Code

This folder holds the reproducible analysis scripts that interpret the thesis study materials.

## Current scope

- `phase1/` contains the card-sort analysis workflow used to summarize placement counts, set-aside reasons, plurality agreement bands, and heatmaps from the exported JSON files.

## Intended separation

- `data/` = raw study inputs and materials
- `analysis/` = code that transforms those inputs into evidence
- `results/` = generated tables, plots, and exported artifacts

This separation follows the thesis narrative: analysis code explains the method, while `results/` stores the study outputs that support the claims.
